Vulnerability Knowledge Base

Learn about different types of mass assignment vulnerabilities and how to prevent them

Lombok @Data Exposure

HIGH RISK

Entity classes using @Data annotation expose sensitive fields through auto-generated setters

Vulnerable Code:
@Entity
@Data
public class User {
    private String username;
    private boolean isAdmin; // VULNERABLE
}
Mitigation:

Use @Getter and selective @Setter annotations instead of @Data

Direct Entity Binding

HIGH RISK

Controllers directly bind @RequestBody to entity classes without DTO layer

Vulnerable Code:
@PostMapping("/users")
public User create(@RequestBody User user) {
    return userService.save(user);
}
Mitigation:

Create DTO classes for request binding and map to entities in service layer

Unsafe Jackson Config

MEDIUM RISK

Jackson deserialization configured to ignore unknown properties

Vulnerable Config:
spring:
  jackson:
    deserialization:
      fail-on-unknown-properties: false
Mitigation:

Set fail-on-unknown-properties to true or implement property whitelisting

Missing Input Validation

MEDIUM RISK

Request parameters lack proper validation annotations

Vulnerable Code:
public void updateUser(@RequestBody User user) {
    // No @Valid annotation
}
Mitigation:

Add @Valid, @NotNull, and other validation annotations

Installation & Setup

Get started with SpringSecure in your project:

Maven Integration

<plugin>
    <groupId>com.springsecure</groupId>
    <artifactId>mass-assignment-detector</artifactId>
    <version>1.0.0</version>
    <executions>
        <execution>
            <goals>
                <goal>scan</goal>
            </goals>
        </execution>
    </executions>
</plugin>

Gradle Integration

plugins {
    id 'com.springsecure.mass-assignment-detector' version '1.0.0'
}

massAssignmentDetector {
    reportFormat = 'HTML'
    failOnHigh = true
}

Standalone JAR

# Download the standalone JAR
wget https://releases.springsecure.com/v1.0.0/detector.jar

# Run the scan
java -jar detector.jar --source-path ./src --report-path ./security-report.html

Basic Usage

Learn how to run scans and interpret results:

Command Line Usage

# Basic scan
springsecure scan --project /path/to/spring-boot-project

# With custom configuration
springsecure scan --project /path/to/project --config security-config.yml

# Generate JSON report for CI integration  
springsecure scan --project . --format json --output security-report.json

Configuration File Example

# springsecure-config.yml
scanner:
  includePatterns:
    - "src/main/java/**/*.java"
  excludePatterns:  
    - "src/test/**"
  
  rules:
    lombokDataCheck: true
    directEntityBinding: true
    unsafeJacksonConfig: true
    missingValidation: true

reporting:
  format: "HTML"
  includeSourceCode: true
  severityThreshold: "MEDIUM"

CI/CD Pipeline Integration

Integrate security scanning into your development workflow:

GitHub Actions

name: Security Scan
on: [push, pull_request]

jobs:
  security-scan:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Setup Java
      uses: actions/setup-java@v2
      with:
        java-version: '11'
    - name: Run SpringSecure Scan
      run: |
        mvn springsecure:scan
    - name: Upload Security Report
      uses: actions/upload-artifact@v2
      with:
        name: security-report
        path: target/springsecure-report.html

Jenkins Pipeline

pipeline {
    agent any
    stages {
        stage('Security Scan') {
            steps {
                sh 'mvn springsecure:scan'
                publishHTML([
                    allowMissing: false,
                    alwaysLinkToLastBuild: true,
                    keepAll: true,
                    reportDir: 'target',
                    reportFiles: 'springsecure-report.html',
                    reportName: 'Security Report'
                ])
            }
        }
    }
}

Advanced Configuration

Customize the scanner behavior for your specific needs:

Rule Configuration

rules:
  lombokDataCheck:
    enabled: true
    severity: "HIGH"
    excludeFields: ["id", "createdAt", "updatedAt"]
  
  directEntityBinding:
    enabled: true  
    severity: "HIGH"
    allowedControllers: ["PublicApiController"]
  
  unsafeJacksonConfig:
    enabled: true
    severity: "MEDIUM"
    checkFiles: ["application.yml", "application.properties"]

Custom Annotations

# Support custom security annotations
annotations:
  safeForBinding: 
    - "com.company.annotations.SafeBinding"
    - "com.company.annotations.PublicField"
  
  excludeFromScan:
    - "com.company.annotations.LegacyCode"
    - "com.company.annotations.Reviewed"
