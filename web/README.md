# Web Version (Archived)

This folder contains the original web-based version of the SpringSecure Mass Assignment Vulnerability Detection Tool.

## Files

- **index.html** - Web UI
- **style.css** - Styling
- **app.js** - Client-side JavaScript logic

## Usage

Open `index.html` in a web browser to use the interactive web interface.

## Note

This version has been superseded by the CLI tool in the root directory, which offers:
- Better performance
- Batch processing
- CI/CD integration
- Multiple output formats
- Proper Java AST parsing

For production use, please use the CLI tool instead.
